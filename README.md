A clean, dark-themed developer portfolio built with plain HTML, CSS, and JavaScript.

## 🚀 How to Push to GitHub

### Step 1 — Create a GitHub Repository
1. Go to [github.com](https://github.com) and log in
2. Click **"New"** (green button) or go to `github.com/new`
3. Name it: `portfolio` (or `damsath-portfolio`)
4. Set it to **Public**
5. **Do NOT** check "Add a README" — leave it empty
6. Click **"Create repository"**

### Step 2 — Set Up Git Locally
Open your terminal / command prompt in the folder where `index.html` is saved:

```bash
git init
git add .
git commit -m "Initial commit: portfolio website"
```

### Step 3 — Connect & Push to GitHub
Copy the repo URL from GitHub (looks like `https://github.com/YOUR_USERNAME/portfolio.git`), then run:

```bash
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git branch -M main
git push -u origin main
```

### Step 4 — Enable GitHub Pages (Live Website!)
1. Go to your repo on GitHub
2. Click **Settings** → **Pages** (left sidebar)
3. Under "Branch", select `main` → `/ (root)` → click **Save**
4. Wait ~1 minute, then your site will be live at:
   `https://YOUR_USERNAME.github.io/portfolio`
